Old Fashioned Typesetting

Old fashioned typesetting was done using a variety of different physical tools. Organizing text was done using a physical medium and then printed copies would be created using a master copy named a "chase". Reformatting was extremely difficult and fonts, colours and styles were very limited.

Desktop Publishing, HTML and CSS

Desktop publishing, HTML and CSS have made typesetting a lot more fluid in how it is approached. Text can be re-organized and changed on a whim, which let's creativity take a spotlight in the digital world. Mistakes can be undone with a few presses of buttons as opposed to re-hauling an entire production line.
